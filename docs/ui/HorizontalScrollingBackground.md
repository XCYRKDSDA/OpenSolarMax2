# 功能规格

## 外观

- 组件直接在当前整个视口上绘制。
- 组件将背景纹理缩放至填充视口高度；水平方向周期性绘制，保证铺满视口。
- 组件维护两个状态用于控制背景的水平位移：「纹理锚点」和「视口目标点」。纹理锚点是背景纹理自身坐标下的一个水平坐标点；视口目标点是该组件希望上述锚点在视口坐标系下所在的水平位置，并以视口中心为原点。
- 称纹理锚点在视口中的位置为「视口锚点」。视口锚点保持和视口目标点相同的坐标系。当视口尺寸发生变化时，组件将保证视口锚点的坐标值不发生变化。
- 组件维护一个「不透明度」状态用于控制背景的不透明度。

## 控制

- 组件提供两种对实际状态的控制模式：「自动模式」和「手动模式」。
- 自动模式下，组件使用线性控制律使实际状态进行「收敛」：以视口目标点为控制目标，以视口锚点为控制对象，计算偏差，乘以收敛比例系数 k 得到速度，并以该速度将视口锚点拉向视口目标点。
- 手动模式下，组件关闭线性控制律，视口锚点永远立即等于视口目标点。

## 程序接口

### 内容

- 背景纹理：Texture2D?，默认为空。
- 不透明度：浮点，可读写，默认为 1。

### 配置项

- 控制模式：枚举，可选自动和手动；默认自动。
- 收敛比例系数：控制律中速度与偏差的比例 k，默认每秒 5，数值越大收敛越快。

### 控制接口与状态报告

- 纹理锚点：浮点，可读写。坐标为纹理坐标系下像素，0 为纹理左边沿。默认为 0。当修改纹理锚点时，组件将按照上一次绘制时的视口尺寸更新视口锚点的位置，以保证纹理在画面中位置不动。
- 视口目标点：浮点，可读写。坐标为视口坐标系下像素，0 为视口中心。默认为 0。
- 视口锚点：浮点，可读写。坐标为视口坐标系下像素，0 为视口中心。写入时立刻生效，组件立刻将纹理锚点移动到写入的位置。默认为 0。
