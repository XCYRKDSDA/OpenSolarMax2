# 功能规格

## 外观

- 组件直接在当前整个视口上绘制。
- 组件将背景纹理缩放至填充视口高度；水平方向周期性绘制，保证铺满视口。
- 组件维护一个「实际偏移」状态用于控制背景的水平位移。当实际偏移为 0 时，背景纹理的左侧对齐视口的中心。
- 组件维护一个「不透明度」状态用于控制背景的不透明度。

## 控制

- 组件提供两种对背景实际偏移的控制模式：「自动模式」和「手动模式」。
- 自动模式下，组件使用线性控制律使背景的实际偏移进行「收敛」：以「目标偏移」为控制目标，计算与当前实际偏移的偏差，乘以收敛比例系数 k 得到当前帧实际偏移的变化速度。
- 手动模式下，组件关闭线性控制律，实际偏移永远立即等于目标偏移。

### 目标偏移设置方式

- 组件提供三种设置目标偏移的方式。三种方式设置的目标偏移会相互覆盖：
    - 索引映射：组件维护一个「索引到目标偏移的映射」，并允许用户设置「目标索引」，组件自行映射为目标偏移。
    - 增量：组件允许用户传入目标偏移值的变化量，并乘以一个「增量偏移倍率」，然后累加到当前目标偏移上。
    - 全量：组件允许用户直接设置目标偏移值。

## 程序接口

### 内容

- 背景纹理：Texture2D?，默认为空。
- 不透明度：浮点，可读写，默认为 1。

### 配置项

- 控制模式：枚举，可选自动和手动；默认自动。
- 索引映射：只需为部分索引指定目标偏移，其余索引按相邻的已指定索引线性插值补全；默认为空。
- 索引外推倍率：目标索引落在索引映射的索引范围外时，目标偏移等于最近一个已指定索引的目标偏移，加上两者索引之差与该倍率的乘积；索引映射为空时，目标偏移等于目标索引与该倍率的乘积。默认为 960。
- 增量偏移倍率：增量设置中施加于传入值的乘数。默认为 2。
- 收敛比例系数：控制律中速度与偏差的比例 k，默认每秒 5，数值越大收敛越快。

### 控制接口与状态报告

- 实际偏移，浮点，可读写，初始时为 0。手动模式下，对该属性的写入会直接同步到目标偏移，不等下一次更新。当模式切换到手动时，实际偏移立刻取到目标偏移。
- 目标偏移，浮点，可读写，初始时为 0。手动模式下，对该属性的写入会直接同步到实际偏移，不等下一次更新。
- 目标索引设置方法，传入整型，组件按索引映射得出目标偏移。
- 增量偏移传入方法，传入浮点，组件自行乘上增量偏移倍率后累加到目标偏移。
