# 功能规格

## 外观

- 组件直接在当前整个视口上绘制。
- 组件将背景纹理缩放至填充视口高度；水平方向周期性绘制，保证铺满视口。
- 组件维护一个「实际居中点」状态用于控制背景的水平位移。该点是背景纹理自身坐标系下的一个横坐标点位，以纹理像素计。「实际背景位移」是它按当前缩放换算出的视口坐标系读数，以画面像素计。当实际居中点为 0 时，背景纹理的左侧对齐视口的中心。
- 组件维护一个「不透明度」状态用于控制背景的不透明度。

## 控制

- 组件提供两种对实际状态的控制模式：「自动模式」和「手动模式」。
- 自动模式下，组件使用线性控制律使实际状态进行「收敛」：以「目标居中点」为控制目标，计算与当前实际居中点的偏差，乘以收敛比例系数 k 得到当前帧实际居中点的变化速度。偏差按当前缩放换算即位移偏差，两种表述的收敛快慢一致。
- 手动模式下，组件关闭线性控制律，实际居中点永远立即等于目标居中点，两种实际读数随之等于两种目标读数。

### 目标设置方式

- 「目标居中点」与「目标背景位移」描述同一个控制目标，对应两种设置意图：
    - 内容导向：调用方关心背景图上哪块内容对准视口中心，设置「目标居中点」。该点是背景纹理自身坐标系下的一个横坐标点位，以纹理像素计，与视口尺寸无关。
    - 位移导向：调用方关心背景挪了多远，设置「目标背景位移」。该量是视口坐标系下背景的水平位移，以画面像素计。
- 组件以目标居中点为存储状态：视口尺寸改变或更换纹理时，目标居中点保持不变，目标背景位移按新的缩放重新换算，数值相应变化。
- 二者按视口与纹理的高度比例换算：目标背景位移 = −目标居中点 ×（视口高度 ÷ 纹理高度）。负号表示变化方向相反。以下会同时使用这两个概念，不再赘述换算逻辑。
- 组件提供三种设置方式。三种方式设置的结果会相互覆盖：
    - 位置映射（内容导向）：组件维护一个「位置到目标居中点的映射」，并允许用户设置「目标位置」，组件自行映射为目标居中点。用户还可设置当目标位置位于映射表范围外时的外推比例。
    - 增量（位移导向）：组件允许用户传入目标背景位移值的变化量，并乘以一个「增量位移倍率」，然后累加到当前目标背景位移上。
    - 全量（两种意图各有入口）：组件允许用户直接设置目标居中点坐标或目标背景位移值。

## 程序接口

### 内容

- 背景纹理：Texture2D?，默认为空。
- 不透明度：浮点，可读写，默认为 1。

### 配置项

- 控制模式：枚举，可选自动和手动；默认自动。
- 位置映射：位置到目标居中点的映射。只需为部分位置指定，其余位置按相邻的已指定位置线性插值补全；默认为空。
- 位置外推目标居中点倍率：目标位置落在位置映射的已指定位置范围外时，每远离一个位置单位，目标居中点变化多少纹理像素；位置映射为空时，目标居中点等于目标位置与该倍率的乘积。默认为 960。该属性是存储值，视口尺寸改变时不变。
- 位置外推目标背景位移倍率：目标位置落在位置映射的已指定位置范围外时，每远离一个位置单位，目标背景位移变化多少画面像素；位置映射为空时，目标背景位移等于目标位置与该倍率的乘积。该属性是「位置外推目标居中点倍率」按当前缩放换算的表述，视口尺寸改变时数值变化；写入任一属性会换算更新另一属性。
- 增量位移倍率：增量设置中施加于传入值的乘数，负值表示背景与条目同向移动。默认为 −2。
- 收敛比例系数：控制律中速度与偏差的比例 k，默认每秒 5，数值越大收敛越快。

### 控制接口与状态报告

- 状态以居中点存储：目标背景位移与目标居中点是同一目标状态的两种读数，实际背景位移与实际居中点是同一实际状态的两种读数。写入任一读数即更新该状态，另一读数按当前缩放换算更新；视口尺寸改变时读数的数值变化，状态不变。
- 实际居中点，浮点，可读写，初始时为 0，以纹理像素计，实际状态的存储值。手动模式下，对该属性的写入会直接同步到目标居中点，不等下一次更新。当模式切换到手动时，实际居中点立刻取到目标居中点。
- 实际背景位移，浮点，可读写，初始时为 0，以画面像素计。读写按当前缩放与实际居中点换算。手动模式下，对该属性的写入会换算后同步到目标居中点，不等下一次更新。
- 目标居中点，浮点，可读写，初始时为 0，以纹理像素计，内容导向的设置入口。对该属性的写入会更新目标背景位移的换算读数。手动模式下，对该属性的写入还会直接同步到实际居中点，不等下一次更新。
- 目标背景位移，浮点，可读写，初始时为 0，以画面像素计，位移导向的设置入口。读写按当前缩放与目标居中点换算。手动模式下，对该属性的写入还会换算后同步到实际居中点，不等下一次更新。
- 目标位置设置方法，传入浮点，组件按位置映射求出目标居中点并写入。
- 增量位移传入方法，传入浮点，即条目位移的变化量（画面像素，条目向左移动为正）；组件自行乘上增量位移倍率后按当前缩放换算，累加到目标状态。
