# 功能规格

## 外观

- 控件的可视区域分为上下两部分：上部分为「预览面板」，下部分为「导航条」。导航条高度固定，预览面板占据其余全部高度。

### 导航条

- 「导航条目」横向排开，各自中心点位于同一水平线上，且横向等间距分布。
- 导航条目的中心点均在导航条中竖直居中。
- 导航条目内容由调用方提供。控件不限定条目的外观与类型。
- 所有导航条目中，条目中心到导航条中心水平方向距离最近的，称为「最聚焦的条目」。当导航条中心精准地位于两个条目正中间时，右侧条目为最聚焦的条目。
- 最聚焦的条目的不透明度为 1。其他导航条目的不透明度与其到当前最聚焦的条目的索引距离成线性关系：若当前第 i 个条目最靠近导航条中心，则第 j 个条目的不透明度为 1-k*|i-j|。不透明度最小为 0。
- 导航条正中位置有一个「选中圈」，形状为一圆环。其尺寸和不透明度与最聚焦的条目到中心的像素距离在区间内呈线性关系：当距离为 0 时，选中圈尺寸为内接导航条上下两边，不透明度为 1；当距离半个导航条目间距时（一般情况下的最远距离），尺寸为 0，不透明度也为 0。当距离更远时，尺寸和不透明度保持为 0。

### 预览面板

- 本控件不主动在预览面板内放置任何内容，而是将其暴露给调用方，由调用方在其中按需放置控件，根据本控件后续暴露的状态自行决定如何绘制。

### 动画

> 此处介绍用户不提供任何输入时的行为。当用户输入时，本控件行为见后续章节。

- 「稳态」时，最聚焦的条目一定精准落在导航条正中心。
- 当不处于稳态时，控件将应用一套线性控制律使导航条的位置进行「收敛」：以「收敛目标条目」的中心落在导航条正中心时导航条的水平位置为控制目标，计算与当前水平位置的像素偏差乘以比例 k 得到向其靠近的速度。
- 当导航条的位置接近控制目标时，为了解决计算舍入问题，本控件会采取一些操作保证导航条精准收敛到控制目标，此时可能会违反上述线性控制律。

## 交互

- 使用者在控件范围内（含预览面板）按下并移动，按下后位移的切比雪夫距离大于「单击判定阈值」时视为「拖动」，小于等于阈值即抬起时视为「单击」。按下点必须在控件范围内，按下后的移动可以移出控件范围。
- 单击位置以按下点为准。
- 触控时以第一处落点为准，该触点抬起前，其余触控点不起作用。

### 拖动

- 拖动时，导航条在水平方向严格逐像素跟随拖动轨迹。
- 拖动抬起后，收敛目标条目选为抬起瞬间最聚焦的条目。
- 允许导航条被拖动得越过首尾条目。越界后松开，控制律将使导航条自行收敛回首条目或尾条目，视觉表现为回弹。
- 收敛进行期间再次按下并拖动，收敛中断，改由拖动接管。

### 单击

- 单击导航条时，寻找距离单击点最近的导航条目（若两侧等距则取序号较大者），然后计算单击点到该条目中心的水平距离。若该距离大于「单击条目距离阈值」则视为没有选中，无事发生；否则视为单击选中该条目，将该条目设置为收敛目标条目，随后按无输入时的控制律移动至居中。单击导航条不触发事件。
- 单击预览面板时，触发「确认事件」，确认对象为当前最聚焦的条目。单击预览面板不修改导航条位置。

### 滚轮

- 滚轮向下滚动一格，收敛目标条目切换到当前收敛目标条目的后一个条目；向上滚动一格，切换到前一个条目。切换后按无输入时的控制律移动。
- 收敛目标处于首个条目时，继续向前切换无效果；处于末尾条目时，继续向后切换无效果；不循环。
- 拖动期间忽略滚轮输入。

### 键盘

- 控件获得输入焦点时响应键盘，失去输入焦点时忽略键盘。
- 左、右方向键：收敛目标切换到前一个或后一个条目，行为与滚轮相同。
- 空格或回车键：触发确认事件，与单击预览面板等效。

## 配置项

- 条目间距：相邻导航条目中心的距离，默认 240 像素；修改后对已有条目与其后新增的条目同时生效。
- 导航条高度：默认 160 像素。
- 不透明度衰减系数：导航条目不透明度公式中的 k，默认 0.2。
- 选中圈颜色：默认纯白。
- 选中圈粗细：默认 3 像素。
- 收敛比例系数：控制律中速度与像素偏差的比例 k，默认每秒 10，数值越大收敛越快。
- 单击判定阈值：按下后位移视为拖动的切比雪夫距离阈值，默认 5 像素。
- 单击条目距离阈值：单击点到条目中心的水平像素距离上限，默认 80 像素。

## 内容管理

- 导航条目，ObservableCollection。导航条的显示随之同步更新。条目数量变化后，收敛目标的索引不变，除非其超过了变化后的条目数量范围，此时会自动钳位到集合最后一个条目。当集合从空变为非空时，收敛目标条目自动选为第一个条目。

## 状态报告

- 聚焦状态：
    - 最聚焦的条目的索引，整型。当导航条目集合为空时，该值为 -1。
    - 归一化偏移量，带符号浮点实数，取值范围为 -1~1。当导航条目集合为空时，该值为 nan。
        - 当条目精准聚焦时，本控件保证该偏移量精准为 0；
        - 当条目未精准聚焦时，该偏移量的符号表示导航条中心位于聚焦的条目的哪一侧：正值表示右侧，负值表示左侧；
        - 当偏移量达到条目间距的一半时，该偏移量为 ±1；
        - 即使导航条被拖动得远远超过首尾条目半个间距，该偏移量仍然保持 ±1 的钳位。
    - 当导航条中心正好位于相邻两条目中心的水平方向中点时，最聚焦的条目为右侧条目，归一化偏移量为 -1。
    - 可写。最聚焦条目的索引和归一化偏移量需要同时写入。写入后控件立即跳转到目标位置，但不改变收敛目标条目。写入值超过范围时抛异常。
    - 归一化偏移量允许写入 +1，但当写入的索引不是最后一个条目时，再次读出时会换算为 -1。
    - 写入位置按四舍五入取整为像素，读回值为取整后位置的归一化结果，可能与写入值有不超过一个像素的偏差。
    - 修改条目间距时，本控件保证最聚焦的条目的索引不变、修改前后归一化偏移量换算成的像素位置之差不超过一个像素，以保持视觉和行为上的一致性。
- 收敛目标条目索引，整型。描述当前控制律的目标条目。可写，写入后导航条不立即跳转，而是根据控制律收敛到本属性描述的条目。当导航条目集合为空时，该值为 -1。
- 导航条累计滚动像素位移，整型。零点为第 0 个导航条目精准聚焦时的导航条位置，并以条目索引增大的方向为正向。当导航条目集合为空时，该值为 0。修改条目间距后该值会重算。
- 确认事件，event，汇报确认的条目的索引。当导航条目集合为空时，该事件永不触发。
- 导航条移动事件，event，汇报相对上次触发事件时导航条滚动像素变化量。若导航条未发生移动则不触发。控件创建后不触发，第一次移动时才触发。设置聚焦状态导致的导航条移动也会触发。修改条目间距后也会触发。

## 初始化

- 初始化时若不提供或导航条目集合为空，则导航条停留在零位置，公开的聚焦条目索引和目标条目索引为 -1、归一化偏移量为 nan、导航条像素位移为 0。
- 初始化时若提供非空导航条目集合，则默认首条目精准居中、导航条处于稳态、收敛目标条目为首条目。
